# Security Policy

## Sensitive information

Do not publish:

- API keys;
- passwords or tokens;
- private applicant records;
- proprietary financial information;
- personally identifiable information; or
- confidential organization data.

The Atlas is designed around public aggregate datasets.

## Reporting a vulnerability

Please avoid including secrets or sensitive records in a public GitHub issue. Describe
the software behavior and reproduction steps without exposing confidential information.

## Data-integrity concerns

Incorrect source attribution, stale links, geographic join errors, and misleading index
transformations are also important research-integrity issues and should be reported.
