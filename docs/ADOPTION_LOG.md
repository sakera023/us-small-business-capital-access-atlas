# Verified External Use Log

## Purpose

This file records **verifiable, genuine external use** of the U.S. Small Business Capital
Access Atlas.

Entries are added only when evidence exists. The maintainer does not create fictional
users, testimonials, citations, organizations, or adoption claims.

## Verification standard

A qualifying entry should have at least one of:

- public paper, report, thesis, poster, or syllabus;
- independent repository or notebook;
- attributable external issue / pull request;
- independent replication report;
- public presentation or demonstration;
- documented classroom/research-lab use; or
- accurate organizational-use documentation.

## How to add an entry

1. retain the underlying evidence;
2. verify that the user is genuinely external to the project maintainer;
3. describe what was actually used;
4. avoid broader claims than the evidence supports; and
5. link the public evidence when available.

See [Independent Replication Protocol](REPLICATION_PROTOCOL.md) and
[External Use Evidence Guide](EXTERNAL_USE_EVIDENCE.md).
