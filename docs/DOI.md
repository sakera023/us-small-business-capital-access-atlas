## Citation guidance

Use the **version-specific DOI** when a paper, report, replication, or technical result
depends on version 0.3.0.

Use the **concept DOI** when referring to the evolving Atlas software project and when a
citation should continue to resolve to the latest archived version.

remains **v0.3.0**, and the citation metadata in this repository intentionally points to
the archived v0.3.0 DOI above rather than treating `v2` as a GitHub software version.
