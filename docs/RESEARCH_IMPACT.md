# Research Impact and Adoption Framework

## Purpose

The Atlas is open research software. Its value is strongest when use, reuse, and external
engagement are documented with verifiable evidence.

## Evidence the project can legitimately generate

Examples include:

- public GitHub forks containing substantive derivative work;
- external pull requests;
- reproducible bug reports;
- citations in papers, preprints, reports, posters, syllabi, or theses;
- public notebooks or repositories that import or extend the package;
- documented use by an economic-development, research, or educational organization;
- public presentations or demonstrations;
- independent replication of a map or index result; and
- letters that accurately describe actual organizational use.

## Metrics to track

The maintainer may periodically record:

- GitHub release downloads;
- repository forks;
- substantive pull requests;
- external contributors;
- issue reports from real users;
- public citations;
- public derivative repositories;
- Streamlit usage indicators when available; and
- documented institutional or classroom use.

## Evidence-quality hierarchy

A citation, reproducible derivative implementation, or independently documented use is
more informative than a star or page view.

The repository will not manufacture users, stars, testimonials, citations, or adoption
claims.

## Research dissemination strategy

1. Keep the public app functional and current.
2. Publish versioned GitHub releases.
3. Maintain citation metadata.
4. Add reproducible notebooks and case studies.
5. Invite method and data contributions through public issues.
6. Add authoritative datasets with documented provenance.
7. Seek independent replication and methodological feedback.

## Immigration/legal boundary

This repository documents technical work and public research dissemination. It does not
by itself establish any legal immigration criterion; any use in a petition should rely on
accurate, independently supportable evidence and appropriate legal advice.
