# Case Study 1 — Mid-Atlantic State Comparison

## Research question

How can a researcher compare small-business conditions across Virginia, Maryland, and
neighboring states using multiple official public sources?

## Workflow

### 1. Load SBA state statistics

Open the public Atlas and load the SBA state dataset. Select a state-level measure related
to small-business scale, employment, job creation, or ownership.

### 2. Compare selected states

Use the State Comparison tab and select Virginia, Maryland, and additional comparator
states.

The purpose is not to label one state as "better" or "worse." The comparison identifies
where raw aggregate measures differ and which definitions should be investigated further.

### 3. Add Census CBP context

Load the 2023 Census County Business Patterns state file and compare:

- establishments;
- employment;
- annual payroll; and
- first-quarter payroll.

SBA and Census measures should not be assumed to be interchangeable. Each source has its
own definitions, population coverage, and reference period.

### 4. Review data quality

Use the Data Quality tab before incorporating a measure into a composite score.

### 5. Test index sensitivity

If multiple SBA measures are selected in the Index Lab, inspect the leave-one-metric-out
table. A ranking that moves substantially when one field is removed should be treated as
methodologically fragile.

## Research value

This workflow demonstrates multi-source geographic comparison, transparent transformations,
and robustness checks.

## Limitations

The workflow does not establish why states differ, whether capital is equitably allocated,
or whether a specific business would obtain financing.
