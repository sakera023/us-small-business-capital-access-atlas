# Case Study 3 — High-Growth State Business Context

## Research question

How can the Atlas distinguish business scale from capital-access opportunity in a
fast-growing state economy?

## Workflow

### 1. Inspect business scale

Use Census CBP to examine establishments, employment, and payroll.

### 2. Inspect SBA small-business measures

Use the SBA state workbook to compare small-business statistics and ownership/employment
measures available in the selected worksheet.

### 3. Separate scale from access

A large number of establishments is not itself a measure of capital availability.
Similarly, high payroll does not establish that underserved entrepreneurs have adequate
access to financing.

### 4. Build an exploratory composite only when justified

If an index is created, use component measures that correspond to distinct conceptual
dimensions and document directionality and weights.

### 5. Test robustness

Run leave-one-metric-out sensitivity. If one component dominates the ranking, the
composite should be revised or reported with a clear caution.

## Research value

The case illustrates an important methodological distinction: economic scale, business
activity, and capital access are related concepts but should not be treated as identical.

## Limitations

The Atlas does not infer financing outcomes for individual firms and does not claim a
causal relationship between state economic indicators and funding access.
