# Documented Case Studies

The Atlas case studies show how a researcher or practitioner can use official public data,
geographic visualization, and transparent diagnostics without turning the platform into an
applicant-level lending tool.

1. [Mid-Atlantic State Comparison](01_mid_atlantic_comparison.md)
2. [Rural and Appalachian Research Workflow](02_rural_appalachian_workflow.md)
3. [High-Growth State Business Context](03_high_growth_state_context.md)

The studies are methodological walkthroughs. They intentionally avoid unsupported claims
about any state, community, lender, or population.
